PRINTOPIA STORE — PINK FARM FOOD
================================
Website katalog Food Hay Day bertema Pink Farm.

Isi folder:
- index.html : halaman website
- style.css  : desain Pink Farm responsif
- script.js  : daftar food, pencarian, filter level, keranjang

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html untuk melihat preview lokal.
3. Unggah ketiga file (index.html, style.css, script.js) ke repository GitHub.
4. Di GitHub, buka Settings > Pages, pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.

Catatan:
- Daftar food dan level dimasukkan berdasarkan daftar yang kamu kirim.
- Karena belum ada daftar harga, keranjang menghitung jumlah item, bukan total rupiah.
- Ikon makanan saat ini berupa emoji sebagai placeholder; bisa diganti gambar produk Hay Day asli nanti.
- Ini katalog front-end statis, cocok untuk GitHub Pages.
